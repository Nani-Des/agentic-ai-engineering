# Capstone brief: from agent to accountable agent

**Teams of 3 to 5. Presented Day 4, 14:00 (8 minutes per team + 3 minutes questions).**
Work on it in breakouts at the end of Days 1 to 3 (about 30 minutes a day).

Pick one agent from your own sector (bank, telco, public service, research, education) or extend the course
bank agent. It must use at least two tools, and at least one tool must change something (write, send, pay, book).

## What you present
1. **The agent (Day 1).** Purpose, users, tools, a 60-second live demo or recording.
2. **Quality (Day 2).** Your test set (10+ cases incl. 2 "must refuse"), pass rate, one trace you learned from.
3. **Security (Day 3).** Threat model diagram, top 3 risks with scores, one attack you tried and the control you added.
4. **Governance (Day 4).** Autonomy tier, register entry, approval rules, what you log, and your kill switch.

## Marking rubric (100 points, pass = 60)
| Criterion | 0 to 5 (weak) | 6 to 15 (adequate) | 16 to 25 (strong) |
|---|---|---|---|
| Working agent and tool design | Doesn't run or tools poorly scoped | Runs; tools sensible | Clean tools, clear descriptions, limits enforced in code |
| Evaluation evidence | No tests | Test set and pass rate | Plus failure analysis and a fix shown by a re-run |
| Threat model and defence | Generic risks | Risks specific to their agent | Attack demonstrated, control added and re-tested |
| Governance and presentation | Missing | Tier, owner, logging stated | Coherent policy choices, clear trade-offs, within time |
